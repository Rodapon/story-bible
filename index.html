Adding lore

  1. Pick the folder that fits: characters/, worlds/, locations/, factions/, artifacts/, concepts/, or create a new folder.
  2. Upload a Markdown file named after the entry, such as characters/oathbreaker.md. The first # Heading (or the title: field) becomes the dictionary term.
  3. Wrap important nouns in double brackets, like [[Wyrm]] or [[Soul|souls]], to mark them as keywords.
  4. Commit. GitHub Pages rebuilds in about a minute and the new term is highlighted across the whole site.
